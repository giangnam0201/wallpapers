# Dark & Coding Theme Wallpapers

A collection of 105+ high-quality SVG wallpapers with dark and coding themes.

## Themes

- **Code Editor** - Syntax highlighting, IDE layouts, terminal screens
- **Geometric** - Abstract dark geometric patterns
- **Circuit Board** - PCB traces and electronic patterns
- **Matrix/Digital** - Digital rain, binary patterns
- **Space/Nebula** - Dark cosmic themes with tech elements
- **Gradient** - Beautiful dark gradient compositions
- **Network** - Node connections, mesh patterns
- **Retro Terminal** - Classic green/amber terminal aesthetics

## Formats

SVG source files are in the `svg/` directory. The GitHub Actions workflow automatically converts them to:

- **PNG** (1920x1080, 2560x1440, 3840x2160)
- **JPEG** (1920x1080, 2560x1440, 3840x2160)

Converted files are available in the `png/` and `jpeg/` directories after the workflow runs.

## Usage

Clone this repo and use the wallpapers in any resolution you need. SVG files can be scaled to any size without quality loss.
